# 增补 kT 图的绘图约定

目标：在相同固定 b 样本中，说明轻子相对动量的方向有宽分布，因此以衰变轴对齐不能逐事件恢复真实 b 轴。

图序：(a) 原始 J/psi qx-qy；(b) 固定 b 的轻子 kx-ky；(c) 固定 |b|、衰变轴对齐；(d) b 大小积分、衰变轴对齐。a/b/c 固定 b=20 fm，d 在 20–60 fm 积分。a/c/d 共用 qT 对数色标，b 使用独立的 kT 概率密度线性色标（从零至完整有限像素峰值），两种动量量级使用各自坐标尺度。另附旧矩阵元权重与角度分布的对照，区分竖条形等值线和真正的方向分辨率。

形式：Python/matplotlib quantitative grid + angular diagnostic。沿用真实 Torch 复振幅及既有核取向样本；改变 b 选择时重新计算产生图、偏振密度矩阵和积分图。b 以 1 fm 为步长取 41 个节点，使用原有 2pi b db 权重。

物理边界：Born level、轻子质量为零、全极角接受度、忽略 qT/M 的横向 boost；k=(p+−p−)/2，在此近似下 kT<=M/2。这是衰变运动学分布，不是入射光子的横动量。对 qT<0.17 GeV 的同一 J/psi 样本求边缘分布。旧 image_P 仅为矩阵元权重，不能当作 dN/d²k。原图 c/d 已对完整极角积分，新增图只展示其来源，不修改原来的角积分。

导出：每种结构 PNG/PDF/SVG，15.8×5.5 inch 四栏诊断图，字体保留为可编辑文本；保存 npz、参数来源、重放误差、积分归一化和求积收敛。边界可积奇点用像素面积积分处理，不用点采样峰值或任意平滑。有限像素色标不是无穷分辨率边界峰值。

默认展示与报告使用 *_main.png/pdf/svg，a/c/d 对数着色，b 线性着色；此前输出保留为历史版本。kt_color_scale 配置显式记录 b 图色标。

当前 a/c/d 的 J/psi 动量坐标为 −0.2 至 0.2 GeV/c。b 的轻子相对 kT 图保留完整物理范围及独立线性色标。qT<0.17 GeV/c 的归一化和轻子样本选择保持原定义。b=20 fm 的更新结果保存于 outputs/jpsi_decay_axis_b20。

补充解释图采用同一个已保存的形变样本，依次显示矩阵元权重、含相空间的二维概率密度（线性色标）、同一概率密度（对数色标）、方位角边缘分布。要说明圆形支持域与垂直 b 的角相关可以同时存在，并拆开相空间因素与着色因素。Python/matplotlib，image plate + quant，15.6×5.3 inch，PNG/PDF/SVG、可编辑文字，源数据和角相关统计存档；不修改主图或正演结果。前两种热图的物理量不同，因此使用各自明确标注的色标；后两张密度热图数据完全相同。理想全极角接受度，小 qT/M，质心系轻子质量近似为零。无抽样误差条，也不把当前数据冒充旧截图的精确重现。
