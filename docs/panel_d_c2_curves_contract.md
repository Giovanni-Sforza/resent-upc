# 连续C2曲线：人工选择动量窗口

目的：展示四极形变、八极形变和中子皮的C2(pT)，由用户结合曲线手动讨论观测量窗口。本轮不预设或优化分界，不沿用上一张图的三段阴影或竖线。

数据：复用前一轮从原panel d密度圆周积分得到的341个径向点；C2(q)=∫I(q,alpha)cos(2alpha)dalpha/∫I(q,alpha)dalpha。主图恰为三条结构曲线；辅助图为三条相对球形参照的Delta C2曲线。原点方向未定义，绘图排除q=0点，其余点无平滑、拟合或重训练。

误差：主图显示中心值；辅助图用已有32对取向的原panel-d表达重建同一Cartesian网格，再按原圆周采样方法计算点态1SE阴影。检查取向平均曲线还原保存曲线。阴影仅表示取向积分误差，不是实验误差或同时置信带；确定性球形/skin无该误差。

绘图：沿用Python/matplotlib，quantitative trend，白底，结构颜色固定，三条曲线用线型辅助区分。讨论宽度约210 mm；PNG/PDF/SVG、CSV及NPZ可复用；文字可编辑。不在本轮挑选优选窗口。输出目录outputs/panel_d_c2_curves/b12_original32_20261009，原数据与旧图不改。
