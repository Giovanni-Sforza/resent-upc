# Panel d 结构比值的径向与条件角向分解

本轮目的：把已经讨论的 panel d 形状比拆为环带整体重分布与同半径内方向性变化，帮助观测量设计；不预先将两项分别命名为中子皮或干涉贡献。

数据：严格复用 `outputs/jpsi_observables_revision/b12_20261007` 中 spherical、beta2、beta3、skin 的 `normalized_images[3,0]`。这是原逐阶段比值图的同一批数据：两种纯形变各32对取向；球形和纯skin确定性；b=12–60 fm、步长2 fm、|y|<1。不同于64取向的新角关联结果，也不同于y=0的混合大形变图。本轮不混合这些版本、不启动前向或径迹响应计算。

定义：每幅线性密度已在 q<0.17 GeV/c 内归一化。以同一Cartesian数据的双线性插值在固定q圆周上取样，构造角平均密度 J_theta(q)=(2π)^(-1)∫I_theta(q,alpha)dalpha。径向形状比 R_rad=J_theta/J_0；条件角向比 R_ang=[I_theta/J_theta]/[I_0/J_0]。完整比值 R_full=R_rad R_ang。采用角积分而非角平均时，共同因子2π约去，分解比值不变。径向平均不可用对原ratio的均匀角平均替代，必须保留球形分布权重。圆周取样与原像素网格有离散差，不能把分解称作新的物理近似或无限精度结果。

证据与图型：Python/matplotlib，image plate + quant。
1. 径向变化图：三种结构的径向比值二维映射、同一尺度的径向曲线，显示哪些q范围整体增减。
2. 条件角向变化图：三种结构去除径向分量后的二维比值图，并用(q,alpha)视图显示固定半径的明暗变化。

颜色以百分比变化100(R-1)表示，零对应白色；每类图跨结构共用对称线性色标，径向与角向各自范围明确标注，不截掉极值。沿用原图显示掩膜：q<=0.17且球形密度大于本panel峰值0.1%。灰色仅表示显示范围/低基准密度，不定义观测量。分析区域、坐标和掩膜不能从PNG颜色反推。

图注说明：x沿轻子k轴；有限取向数是数值积分样本数；本轮显示中心估计，未绘取向误差；高q已有b求积敏感性，分解的代数闭合不认证物理效应显著性。外围位置不单独决定干涉或衍射机制。
