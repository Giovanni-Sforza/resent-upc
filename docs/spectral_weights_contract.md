# Panel d 宽环带谱权重

目标：把形变和中子皮引起的动量谱重新分配，转化为可直接计数的事件份额和两个产额比；展示当前参数点的响应方向，不预先宣称参数可辨识或实验可测。

默认示例区间为L=[0.03,0.08)、M=[0.08,0.13)、H=[0.13,0.17] GeV/c。避开极中心区，并扩大此前过窄的外环。边界可配置，属于探索性选择；本轮不优化显著性或自动挑选最优边界。所有结构共用同一个窗口和同一组边界。

主统计直接取原panel d的normalized_images[3,0]，N_k为环带内线性像素强度的面积积分；f_k=N_k/(N_L+N_M+N_H)，R1=N_M/N_L，R2=N_H/N_M。不平均比值图、不使用显示掩膜。份额只在当前选定窗口归一化，与此前0–0.17范围的份额不可直接混用。原数据的整体归一化对这些比值约去。

来源为outputs/jpsi_observables_revision/b12_20261007，b=12–60 fm、步长2 fm、|y|<1、完整相干信号。复用球形、beta2_mid/beta2、beta3_mid/beta3、skin_mid/skin共7组；各形变32对取向，球形和skin确定性。不重新运行前向模型。

误差：对保留的原始取向强度重新投影到同一像素网格，只用于求解取向积分1SE及共同分母造成的协方差；先平均强度再取比。确定性样本的零取向误差不表示无模型或实验误差。附少量预定边界扰动以检查响应方向，不从扫描中挑选最强信号。

图件：沿用Python/matplotlib，quantitative grid。第一组展示径向概率密度、其相对球形变化、三环带事件份额及其相对变化；第二组展示两个产额比的响应和二维响应坐标，中间参数点用于显示现有离散响应。连接线只引导视线，不代表拟合或连续参数插值。颜色按结构固定、误差定义明确。PNG/PDF/SVG讨论尺寸约210–230mm，矢量文字可编辑，同时导出CSV、NPZ、配置、哈希和数值/图件检查。
